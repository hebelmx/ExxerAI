
# 🧭 Guía para Pedir Ayuda a una IA como ChatGPT en un Proyecto de Python

### 👩‍💻 Perfil de Usuario: Principiantes en Python, con conocimiento básico de computación.

---

## 🛠️ 1. Cómo Empezar una Conversación

Usa siempre lenguaje claro, natural, y explica el contexto.

**Ejemplo:**

```text
Hola, estoy trabajando en un proyecto donde tengo que extraer datos de documentos PDF del IMSS. Estoy usando Python y pandas. ¿Me puedes ayudar a extraer la tabla de una página PDF usando `pdfplumber`?
```

---

## 📘 2. Usar Instrucciones Claras y Dividir el Problema

Si tu problema es complejo, divídelo en pasos. La IA puede ayudarte paso por paso.

**Ejemplo:**

```text
Paso 1: ¿Cómo leo un archivo PDF desde una carpeta?
Paso 2: ¿Cómo encuentro una tabla y convertirla a DataFrame?
Paso 3: ¿Cómo exporto el resultado a Excel?
```

---

## 🧩 3. Pedir Explicaciones Detalladas y Comentadas

Siempre pide que el código esté comentado para que puedas entenderlo y aprender.

```text
¿Puedes explicarme este código paso a paso con comentarios? Estoy empezando en Python.
```

---

## 🛠️ 4. Pedir Ayuda para Corregir Errores

Copia y pega el mensaje de error completo y pregunta qué significa.

**Ejemplo:**

```text
Recibí este error al correr el script:
ModuleNotFoundError: No module named 'openpyxl'
¿Puedes explicarme qué significa y cómo lo soluciono?
```

---

## 🧠 5. Pedir Alternativas o Personalizaciones

Si algo no te gusta del código, pide una versión diferente.

```text
¿Puedes hacer que este script use un input en consola para elegir la carpeta?
```

---

## 🧰 6. Pedir Buenas Prácticas

Aprende mientras desarrollas. Siempre puedes preguntar si el código está bien escrito o cómo mejorarlo.

```text
¿Este código sigue buenas prácticas? ¿Hay alguna forma más elegante de hacerlo?
```

---

## 🧼 7. Limpiar, Documentar o Reusar el Código

Puedes pedir que el código se organice mejor o se haga reutilizable.

```text
¿Puedes convertir esto en una función reutilizable?
```

---

## 💬 8. Pedir Formatos Especiales (por ejemplo Excel, PDF, JSON)

```text
¿Puedes hacer que los datos extraídos se guarden en un archivo Excel con una hoja por cada año?
```

---

## 🧑‍🎓 9. Aprender lo que estás haciendo

No te limites a copiar. Siempre que puedas, pregunta por qué funciona lo que estás copiando.

```text
¿Puedes explicarme por qué usamos `enumerate()` en este código?
```

---

## 🧠 10. Revisar lo Hecho

Pide ayuda para revisar que el script completo cumpla con todos los requisitos.

```text
Este es mi código final. ¿Puedes revisar si cumple con los objetivos del proyecto? ¿Qué mejorarías?
```

---

## 🎓 Tips de Estilo

- ✅ Usa lenguaje amable y claro
- ✅ Pide ayuda paso a paso
- ✅ Sé paciente contigo misma — programar es un proceso iterativo

---

## 🧾 Puedes comenzar con algo como esto:

```text
Hola, tengo este script que recorre PDFs y extrae datos, pero no funciona como espero. ¿Puedes ayudarme a convertirlo para usar pdfplumber y que lea bien las tablas?
También quiero que el Excel tenga una hoja por cada año.
Soy nueva en Python, así que necesito que esté comentado paso a paso.
```
